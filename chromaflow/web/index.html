Chromaflow

A music visualizer built on three old, good ideas — a flow field that drags the whole picture somewhere new each frame, a wave shape that draws the sound as a parametric curve, and a color map that turns raw intensity into light — rebuilt on the GPU with a million particles, live-editable expressions, and modern beat, tempo and key detection.

Those three ideas come from SoundSpectrum’s G-Force, WhiteCap and Aeon, whose config scripting and PythonCanvas API this is an homage to. Full credit below.

Pointer, touch & controllers

Drag to push the flow field around (multi-touch works). Click or tap to detonate a burst. Scroll or pinch to zoom. Connect a MIDI controller and the first eight CC knobs map to the Mix sliders. On a phone, enable tilt to steer with the accelerometer.

Credit where it is due

Chromaflow is an independent, from-scratch homage to the visualizers made by SoundSpectrum — G-Force, WhiteCap, SoftSkies and Aeon, the art of Drew O'Meara and still actively developed — and to two pieces of their documentation in particular: the G-Force config programming guide (WaveShapes, FlowFields, ColorMaps — and the exact five-step per-frame loop this engine follows) and the Aeon PythonCanvas drawing API (its SetDrawClass / Draw(self, fft, time) scene contract, kept on purpose in the Python build's chromaflow/scene.py). No SoundSpectrum code, art, presets or config syntax are used here; the debt is one of architecture and ideas, not of text — see CREDITS.md in the repository for the full account, and consider trying the real thing.

Everything else is new work, released into the public domain — see the repository for the Python engine that carries the same ideas to the desktop.
